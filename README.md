# Cedar Junction

A modern website concept for [Cedar Junction](https://cedarjunction.co.za/), the family theme park and party venue in Zwavelpoort, Pretoria East.

The live preview covers the commercial pages the current brochure site struggles with:

- Home — season status, entrance fees, attractions, party path
- Lapas — filter by type, zone and capacity instead of a long price list
- Parties — day visit, spark party, Whistle Stop, school groups
- Book — a four-step visit plan saved in the browser (not a live payment)
- Activities, gallery and visit notes (hours, rules, winter closures)

Prices and rules follow the park’s published 2026/2027 season notes (adults R150, children 2–12 R130, lapas about R300–R600, card only, bookings essential). This is a design prototype, not the official booking system.

## Run

```bash
npm install
npm run dev
```

The dev server listens on port 8080.
