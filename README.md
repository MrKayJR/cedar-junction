# Cedar Junction

A website concept for [Cedar Junction](https://cedarjunction.co.za/), the family theme park and party venue in Zwavelpoort, Pretoria East.

## Static site (HTML, CSS, JavaScript)

The folder [`docs/`](docs/) is plain HTML. No install and no build.

- Open `docs/index.html` in a browser, or
- serve the folder with any static host.

GitHub Pages is set to publish this folder. The public address is:

https://mrkayjr.github.io/cedar-junction/

Pages: home, activities, filterable lapas, party packages, gallery, visit notes, and a four-step booking request saved in the browser. It is not connected to the park’s real diary or card payments.

## React prototype

The rest of this repository is the earlier Vite / React version.

```bash
npm install
npm run dev
```

That server listens on port 8080. It cannot run from GitHub by itself.
